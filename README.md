# Quote Scope Check

A free, local HTML checklist for noticing missing details before you send a service quote. Original tool from Practical Workbooks, created with AI assistance.

## Try it without an email or account

1. On this repository, choose **Code → Download ZIP**.
2. Extract the ZIP on your computer.
3. Open **quote-scope-check.html** in a current desktop browser.
4. Enter fictional or redacted notes, then choose **Build review summary**.
5. Use **Download TXT**, and check that your browser saved the file before closing.

The tool needs no installation, server, AI API or paid subscription. GitHub is the distribution channel; there is no hosted web app in this repository.

## What it checks

Seven sections: deliverables, exclusions, assumptions, approval owner, changes/revisions, timing, and price/payment terms.

Empty sections are listed as missing. Filled sections are labeled **Text entered; not verified**. A one-word or contradictory entry still passes: the tool checks presence only. You must assess meaning, suitability and price yourself.

There is no autosave, local storage, cloud sync, bank connection or payment processing. Notes remain in the current page until it closes/reloads or you clear them. Export before leaving. Do not enter sensitive customer records, credentials or access codes.

Desktop Chromium UI and TXT download were checked with fictional examples during release QA. Phone behavior, other browsers, native printing/PDF and downloaded-file behavior have limited verification. Clipboard permissions may block Copy TXT; use Download TXT or manually copy the summary. See [START-HERE.md](START-HERE.md) for complete limits.

## A copyable checklist

- What will you deliver?
- What is excluded?
- Which assumptions affect the estimate?
- Who approves the work?
- How will changes or revisions be handled?
- What timing has been discussed?
- What price/payment details need to be recorded?

This is a planning reminder, not a contract, legal review or readiness certification.
